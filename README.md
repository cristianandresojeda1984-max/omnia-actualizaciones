# omnia-actualizaciones
Instaladores y actualizaciones de OmnIA

Acá se publican el **instalador para Windows** y los **paquetes de actualización** de OmnIA (sin el código fuente).
Las PC con OmnIA instalado buscan la última versión en `releases/latest/download/ultima.json`.

Para instalar OmnIA: bajá `OmnIA-instalador-X.exe` de la última versión (Releases) y ejecutalo.
